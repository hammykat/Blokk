# Blokk___Game-Engine
A beginner-friendly, open source 2D game engine with a custom language that transpiles to C + RayLib, for a beginner-friendly, yet extremely fast game for devs!

It will include many featuers that make game development easy, and it will contains a custom language called blokkLang, which is easy to use a powerful with many features. The language is designed to be:
- Easy to learn
- Fast to compile
- Lightweight
- Beginner friendly
- Powerful without unnecessary complexity
